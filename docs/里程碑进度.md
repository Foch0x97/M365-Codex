### 超出计划的增量

计划 §M8 才要求「旧账号一次性迁移」，但用户的 M365 Native 授权助手正好产出同构的
`accounts.json`，提前落地可以直接解除测试对账号有效期的依赖，因此在 M2 一并实现：

- **账号导入器**：读取 `accounts.json`，按 `tid + oid` 去重，只读源文件（测试断言源文件逐字节不变），单条损坏不影响其余账号，返回值与日志只有计数与脱敏邮箱。
- **外部账号文件同步**：配置 `EXTERNAL_ACCOUNTS_FILE` 后按 mtime 变化周期性同步。配合在 Docker 中持续刷新 Token 的 M365 Native 容器，账号过期不中断测试。同步失败只记日志，不拖垮服务。

### 与上游对接的参数

全部走配置，默认值来自公开的 Microsoft 原生客户端 PKCE 流程（均非机密）：

| 项 | 环境变量 | 默认值 |
|---|---|---|
| 客户端 ID | `OAUTH_CLIENT_ID` | `c0ab8ce9-…-33d422df41f1` |
| 回调地址 | `OAUTH_REDIRECT_URI` | `…/common/oauth2/nativeclient` |
| 授权端点 | `OAUTH_AUTHORIZE_URL` | `…/common/oauth2/v2.0/authorize` |
| Token 端点 | `OAUTH_TOKEN_URL` | `…/common/oauth2/v2.0/token` |
| scope | `OAUTH_SCOPES` | `sydney/M365Chat.Read`、`sydney/sydney.readwrite`、`offline_access`、`openid`、`profile` |

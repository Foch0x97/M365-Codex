## 下一步

进入 **M2 · OAuth 与账号健康**：

1. 独立 PKCE 授权流程（独立会话、10 分钟过期、授权码单次消费、`state` 严格匹配）
2. Token 刷新与轮换（同账号单刷新任务、原子替换、加密入库）
3. 账号状态机：`probing` / `online` / `busy` / `cooldown` / `reauth_required` / `disabled` / `unsupported` / `error`

DoD：并发授权互不干扰；`invalid_grant` 转 `reauth_required`；Token 不进入任何日志；集成测试覆盖授权码单次消费与刷新流程。

> 注意：M2 涉及真实 Microsoft OAuth 端点与 CLIENT_ID 配置。按护栏要求，编码阶段只搭框架与模拟上游测试，**不处理任何真实凭据**。
